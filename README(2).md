# Streamlit Fitness & Activity Dashboard

## 1. Required file

Use the `daily_master_clean.csv` generated by your Jupyter/Colab notebook.

Optional files:
- `hourlySteps_merged.csv`
- `hourlyCalories_merged.csv`
- `heartrate_seconds_merged.csv`

## 2. Install packages

```bash
pip install -r requirements.txt
```

## 3. Run the dashboard

```bash
streamlit run app.py
```

The browser will open the Streamlit dashboard.

## 4. Dashboard sections

- KPI cards
- Daily step distribution
- Average steps by weekday
- Daily activity trend
- Activity-level distribution
- Steps vs calories
- Heart-rate analysis
- Sleep analysis
- Weight and BMI trends
- Optional hourly activity profile
- Data completeness
- Correlation matrix
- User-level summary
- Filtered CSV download
